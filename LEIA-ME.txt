PROJETO REFUGIO - Etapas 0 e 1
==============================

COMO USAR
1. Descompacte esta pasta (refugio) onde quiser.
2. Instale o Roblox Studio (https://create.roblox.com) se ainda nao tiver.
3. De dois cliques em setup.bat. Ele instala/configura Git, VS Code,
   Rokit + Rojo, o plugin do Rojo e as extensoes do VS Code.
   Se pedir, feche a janela e rode de novo (o Windows precisa reconhecer
   os programas recem-instalados).
4. No Roblox Studio:
   - crie um Baseplate e publique como privado;
   - Game Settings > Security > ative "Enable Studio Access to API Services"
     (sem isso o salvamento nao funciona no Studio).
5. De dois cliques em iniciar.bat (roda "rojo serve") e, no plugin do
   Rojo dentro do Studio, clique em Connect.

TESTE DA ETAPA 1
- Aperte Play: o placar mostra Visitas = 1.
- Pare e aperte Play de novo: Visitas = 2.
- Se passou de 1 para 2, o salvamento funciona. Faca o commit:
    git add .
    git commit -m "Etapa 1: perfil persistente"
